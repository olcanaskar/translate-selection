Why Translate Selection?

No new tabs

A compact card appears next to the text you selected.

Other meanings

Single words also show dictionary meanings grouped by type.

Quick language switch

Change the target language from the card and retranslate instantly.

Nearly 60 languages

An alphabetical language list with light and dark themes.

Keyboard and context menu

Use Ctrl + Shift + Y or right-click the selected text.

Privacy-minded

Only selected text is sent, and only when you request a translation.

Install in about a minute

  1. Download the latest release ZIP and extract it to a folder you will keep.
  2. Open brave://extensions (or the matching page for your browser).
  3. Turn on Developer mode and click Load unpacked.
  4. Select the extracted folder, then refresh open tabs.

The Chrome Web Store requires a paid developer registration. This project is distributed as a free GitHub release instead. Browsers may show a developer-mode extension notice; this is normal.

Privacy

No analytics, ads, accounts, or developer servers. Selected text is sent to Google Translate only when you ask for a translation. Your target language is stored in browser sync storage.
